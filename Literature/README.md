# Literature: Secondary Sources

Secondary sources for *El Salvador's Political Economy of Fiscal Policy, 1953–1980*. They are used for context, interpretation and cross-checks; the project's own figures come from the Memorias de Hacienda (*Memorias de Hacienda/*). Reading notes for each source are in *Reading_Notes/*, as Markdown and Word. Full references are in *Bibliography/Bibliography_External_Sources.md*.
